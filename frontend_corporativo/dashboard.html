Inicio / Deep Learning con TensorFlow & Keras
Subproyecto 2 · Modelo Entrenado con 100k Registros Supabase

Red Neuronal Profunda (Keras Sequential)

Modelo de Deep Learning entrenado con las 100,000 transacciones históricas de Supabase para predecir ventas corporativas y analizar demanda multivariable.

🎯 ¿Por qué es aprendizaje supervisado?

Cada registro de entrenamiento tiene variables de entrada y una etiqueta objetivo. Las entradas son producto, tienda, precio unitario, stock, temperatura, mes y día de la semana; la etiqueta que el modelo aprende a estimar es ventas_totales en soles. El dataset se divide en 80% para entrenamiento y 20% para prueba. La predicción de abajo usa el modelo entrenado y muestra su R² y MAE.

📐 Ficha Técnica de la Arquitectura Keras

• Tipo de Modelo: Deep Neural Network (DNN) con tf.keras.Sequential.
• Capas: Input(14) ➔ Dense(64, ReLU) ➔ BatchNormalization() ➔ Dropout(0.1) ➔ Dense(32, ReLU) ➔ Dense(16, ReLU) ➔ Dense(1, Linear).
• Optimizador: Adam (Learning Rate = 0.002 con reducción por meseta ReduceLROnPlateau).
• Entrenamiento Masivo: 100,000 registros procesados desde Supabase PostgreSQL (80% Entrenamiento, 20% Prueba con EarlyStopping).
• Optimización para la Nube (Render): Arquitectura Dual-Engine que preserva el archivo nativo modelo_ventas_keras.keras y utiliza pesos matriciales exportados para garantizar alta velocidad con menos de 10 MB de RAM.
