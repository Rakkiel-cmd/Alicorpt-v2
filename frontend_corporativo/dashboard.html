Inicio / Deep Learning con TensorFlow & Keras
Subproyecto 2 · Modelo Entrenado con 100k Registros Supabase

Red Neuronal Profunda (Keras Sequential)

Modelo de Deep Learning entrenado con las 100,000 transacciones históricas de Supabase para predecir ventas corporativas y analizar demanda multivariable.

🎯 Inferencia Neural con Datos Corporativos

El modelo procesa la totalidad de las 100,000 transacciones históricas sincronizadas directamente desde la base de datos PostgreSQL en Supabase. Las variables analizadas son producto, tienda, precio unitario, stock, temperatura, mes y día de la semana; la etiqueta que la Red Neuronal estima con alta precisión es ventas_totales en soles. Los indicadores reflejan la capacidad predictiva del modelo sobre el volumen masivo de operaciones reales corporativas.

📐 Ficha Técnica de la Arquitectura Keras

• Tipo de Modelo: Deep Neural Network (DNN) con tf.keras.Sequential.
• Capas: Input(14) ➔ Dense(64, ReLU) ➔ BatchNormalization() ➔ Dropout(0.1) ➔ Dense(32, ReLU) ➔ Dense(16, ReLU) ➔ Dense(1, Linear).
• Optimizador: Adam (Learning Rate = 0.002 con reducción por meseta ReduceLROnPlateau).
• Entrenamiento Masivo: 100,000 transacciones procesadas directamente desde Supabase PostgreSQL con convergencia acelerada y EarlyStopping.
• Optimización para la Nube (Render): Arquitectura Dual-Engine que preserva el archivo nativo modelo_ventas_keras.keras y utiliza pesos matriciales exportados para garantizar alta velocidad con menos de 10 MB de RAM.

Inicio / Segmentación no supervisada
Clustering No Supervisado · Algoritmo K-Means

Aprendizaje no supervisado con K-Means

El algoritmo agrupa las transacciones por similitud, sin utilizar una etiqueta previamente conocida, para identificar perfiles de ventas, stock y demanda.

¿Cómo funciona? K-Means estandariza las variables y encuentra grupos similares usando precio unitario, stock actual, cantidad vendida y ventas totales. El segmento se interpreta después de observar sus promedios; no se le entrega una categoría al algoritmo.
